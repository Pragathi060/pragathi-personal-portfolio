# Pragathi Thallapally - Personal Portfolio

A responsive and accessible Personal Portfolio Web Application developed for
**Full Stack Development Assignment-1**.


## Featured Projects

1. **Movie Info Finder** - Responsive movie search and information interface.
2. **Memory Game** - Interactive card matching game using JavaScript and DOM manipulation.
3. **To-Do List** - Responsive task management application with interactive task handling.
4. **Vehicle Counting System** - Real-time vehicle detection and counting using YOLOv8 and OpenCV.

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- JavaScript ES6+
- Bootstrap Icons

## How to Run

1. Download or clone the repository.
2. Open the folder in VS Code.
3. Open `index.html` in a browser.

For a better development experience, use the **Live Server** extension in VS Code.
